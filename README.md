# Vanilla Style HUD — Minecraft 26.2
Client-side Fabric HUD editor.
Right Shift opens the editor. Drag widgets, right-click for settings, and save positions automatically.
Includes Coordinates/Facing/Biome, FPS/RAM, Sprint/Sneak, Saturation, and Armor Status with durability.
Built automatically by GitHub Actions with Java 25 and Gradle 9.5.1.
